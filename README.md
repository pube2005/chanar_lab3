## 2. Чанарын сценарио

### 2.1. Performance — Сагсанд бараа нэмэх

| Хэсэг | Тодорхойлолт |
|---|---|
| Тойм | Сагсанд бараа нэмэх үйлдлийн хариу хугацааг хэмжих. |
| Системийн төлөв | Express API хэвийн ажиллаж байгаа. |
| Орчны төлөв | 20 VU тогтмол ачаалал, ойролцоогоор 15 cart хүсэлт/секунд, 1 минутын турш. |
| Гадаад өдөөлт | Хэрэглэгч POST /cart/add хүсэлт илгээнэ. |
| Шаардлагатай хариу | Систем HTTP 200 төлөвтэй, амжилттай нэмэгдсэн барааны мэдээллийг буцаана. |
| Хэмжүүр | Хариу хугацааны p95 нь 50 мс-ээс бага байна. |

### 2.2. Reliability — Төлбөрийн найдвартай ажиллагаа

| Хэсэг | Тодорхойлолт |
|---|---|
| Тойм | Төлбөрийн үйлдлийн алдаа гарах магадлалыг хэмжих. |
| Системийн төлөв | API хэвийн ажиллаж байгаа боловч төлбөрийн endpoint-д 5%-ийн санамсаргүй алдаа загварчилсан. |
| Орчны төлөв | 20 VU тогтмол ачаалал, 1 минутын турш. |
| Гадаад өдөөлт | Хэрэглэгч POST /pay хүсэлт илгээнэ. |
| Шаардлагатай хариу | Систем төлбөр амжилттай хийгдсэн мэдээллийг HTTP 200 төлөвтэй буцаана. |
| Хэмжүүр | Төлбөрийн алдаа гарах магадлал (POFOD) 8%-иас бага байна. |

### 2.3. Availability — Системийн хүртээмжтэй байдал

| Хэсэг | Тодорхойлолт |
|---|---|
| Тойм | Серверийн гэнэтийн зогсолтын үеийн хүртээмж болон сэргэх хугацааг хэмжих. |
| Системийн төлөв | API ажиллаж байх үед сервер гэнэт зогсоно. |
| Орчны төлөв | 20 VU ачаалал, 2 минутын турш, 10 секундийн зориудын зогсолттой. |
| Гадаад өдөөлт | Серверийн ажиллагаа гэнэт тасалдах (crash). |
| Шаардлагатай хариу | Сервер дахин асаж, хэрэглэгчийн хүсэлтүүдэд хэвийн хариу өгдөг болно. |
| Хэмжүүр | Хүсэлт амжилттай биелэх магадлал 90%-иас багагүй, сэргэх хугацаа 12 секундээс ихгүй байна. |
